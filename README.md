 # 🚀 Sisay Abebayew - Portfolio

A modern, interactive 3D portfolio built with Next.js, React Three Fiber, and Tailwind CSS.

## ✨ Features

- 🎨 Interactive 3D Scenes - Built with React Three Fiber
- ⚡ Fast Performance - Next.js App Router with server-side rendering
- 📱 Fully Responsive - Works on all devices
- 🎯 Smooth Animations - Framer Motion transitions
- 🌙 Dark/Light Mode - Automatic theme switching
- 🚀 Optimized SEO - Meta tags and Open Graph support

## 🛠️ Tech Stack

- [Next.js 15](https://nextjs.org/)
- [React 18](https://react.dev/)
- [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)
- [Three.js](https://threejs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)

## 📦 Installation

`bash
# Clone the repository
git clone https://github.com/Bboysis/portfolio_next.git

# Navigate to the project
cd portfolio_next

# Install dependencies
npm install
# or
pnpm install

# Start development server
npm run dev
# or
pnpm dev
